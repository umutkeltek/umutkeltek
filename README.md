## Building

- 🔀 **[Switchback](https://github.com/umutkeltek/switchback)** - One Rust binary that routes LLM traffic across providers, with fallback, budgets, and encrypted credentials
- 🩺 **[HealthSave Observatory](https://github.com/umutkeltek/healthsave-observatory)** - Your health data on your own machine. Self-hosted, local-first, egress denied by default
- 🎁 **[agents-wrapped](https://github.com/umutkeltek/agents-wrapped)** - Spotify Wrapped for your coding agents. `npx agents-wrapped`
- ✂️ **[JumpCutter](https://github.com/umutkeltek/jumpcutter)** - Cuts the silence out of videos. Tauri, Svelte, FFmpeg
- 🧱 **Compound** - A local-first control plane for coding agents. *Coming soon*

Also built [SkillAce](https://skillace.ai): role-play simulations that score the soft skills a CV can't show.
